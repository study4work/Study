## Stack (стек)
— это область памяти для временного хранения данных в рамках одного потока. Работает по принципу LIFO (Last In, First Out). Быстрый, но маленький.  
## Heap (куча)
— это область памяти для долговременного хранения объектов. Общая для всех потоков. Большая, но медленнее, требует сборки мусора.

## Escape Analysis + Stack Allocation
   JVM анализирует, "убегает" ли объект за пределы метода. Если не убегает — может разместить его прямо в stack.
