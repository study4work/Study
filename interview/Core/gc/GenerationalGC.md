**Поколения (Generations)** — это разделение heap на области с разным "возрастом" объектов. Основано на гипотезе слабых поколений:  
Большинство объектов умирают молодыми.
## Что такое Young Generation
Young Generation — область heap для новых объектов. Здесь происходит Minor GC (быстрая сборка мусора).  
![img.png](/src/main/resources/images/yongGC.png)
Как работает:  
1. Создание объектов:
```java
User user = new User();  // ← Объект создаётся в Eden
```
2. Когда Eden заполняется:  
   Запускается Minor GC  
   Мёртвые объекты удаляются  
   Живые объекты копируются в Survivor 0 или Survivor 1  
   Eden очищается  
3. Повышение возраста:  
   Каждый объект имеет возраст (age)  
   При каждом GC возраст увеличивается на 1  
   Когда возраст достигает порога (обычно 15) → объект перемещается в Old Generation  
**Особенности Young Generation**:  
✅ Быстрый GC — маленькая область, много мёртвых объектов  
✅ Частый GC — запускается часто (каждые несколько секунд)  
✅ Копирование — живые объекты копируются, мёртвые игнорируются  
✅ Нет фрагментации — после копирования память компактна  

## Что такое Old Generation (Tenured)
Old Generation — область heap для долгоживущих объектов. Здесь происходит Major GC (полная сборка мусора).
Какие объекты попадают в Old Generation:  
1. Объекты, пережившие много GC в Young Generation
2. Большие объекты (Humongous objects в G1 GC)
3. Объекты, созданные напрямую в Old Generation(Некоторые JVM могут размещать объекты сразу в Old, если они явно долгоживущие)  

**Как работает Major GC:**
1. Маркировка (Mark):
```java
Обход всех GC Roots → помечаем все достижимые объекты
```
2. Очистка (Sweep):
```java
Удаляем все непомеченные объекты
```
3. Компактификация (Compact):
```java
Сдвигаем живые объекты в начало, чтобы устранить фрагментацию
```
Особенности Old Generation:  
❌ Медленный GC — большая область, сложные алгоритмы  
❌ Редкий GC — запускается реже (раз в несколько минут)  
❌ Stop-the-world — все потоки останавливаются на время GC  
⚠️ Фрагментация — может потребоваться компактификация
